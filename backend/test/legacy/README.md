# Legacy Test Files

This directory contains old/deprecated test files that are kept for reference but are no longer actively used.

## Files

- `run-all.js` - Old canonical test runner (replaced by `runners/comprehensive.js`)
- `run-all-75-endpoints.js` - Old comprehensive test runner (replaced by `runners/comprehensive.js`)
- `curl-test-all.js` - Old curl-based test runner (replaced by `runners/comprehensive.js`)
- `scripts/` - Old test scripts (replaced by organized runners)

## Migration

All active test functionality has been moved to:
- `runners/` - Active test runners
- `fixtures/` - Test data
- `utils/` - Utility scripts
- `reports/` - Test reports
